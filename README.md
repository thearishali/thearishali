### 🚀 About Me

I am a Data Scientist and AI/ML Engineer with a deep foundation in mathematical modeling, statistical learning, and distributed computing from **IIT Madras**. 

My core focus lies at the intersection of **Applied AI and MLOps / DevOps** — bridging the divide between experimental machine learning and scalable, automated, production-grade cloud systems. I architect reproducible pipelines, containerized microservices, and automated CI/CD workflows for machine learning models.

* 🎓 **Academics:** Pursuing BS in Data Science & Applications at **IIT Madras**, with comprehensive training across Mathematics, Statistics, Machine Learning Practice (MLP), Modern Application Development (MAD), and Cloud Computing.
* 🛠️ **Engineering Philosophy:** Clean code, strict type-hinting, automated testing (`pytest`), containerization (`Docker`), and GitOps-driven delivery.
* 🔭 **Active Focus:** Production MLOps pipelines (DVC + MLflow), Generative AI / Agentic systems with quantitative evaluation frameworks, and high-performance inference serving.
